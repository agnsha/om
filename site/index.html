Systems speed, simpler code.A compiled language aiming for Rust-level performance, faster builds and no lifetime annotations. Built for backend services.

Get startedRead the design

Early and experimental: phase 0 of 6. The compiler builds real native executables today; ownership, structs and generics come next.

fib.omnative, via Cranelift
fn fib(n: i64) -> i64 {
    if n < 2 { n } else { fib(n - 1) + fib(n - 2) }
}

fn main() {
    print("Hello, Om!")
    let mut i = 0
    while i < 5 {
        print(fib(i * 5))
        i = i + 1
    }
}

What Om is aiming for

≈ Rust

Runtime speed

Static types, no garbage collector, generics compiled to specialised code. Release builds will use LLVM, the optimizer Rust uses.

Faster builds

Compile time

Dev builds use Cranelift, a fast code generator, and a type checker with no lifetime solving.

0 lifetimes

Simpler ownership

Borrow inside a function call, own everything else. Moves and safety as in Rust, without lifetime syntax.

1 reset

Per-request memory

Servers get a memory region per request: allocation is a pointer bump and the whole request is freed in one step.

These are design goals. Benchmarks against Rust, C and Go arrive in phase 5 and will be published in full, including where Om is slower.

From source to native binary in five stations

The compiler is written in Rust and split into small crates you can read in an afternoon.

Lexertext to tokens, each with its source span
Parserrecursive descent to a syntax tree
Checkertypes, names and clear errors with a caret
CraneliftSSA IR to machine code for x86-64 or ARM64
Linkerobject file plus a tiny runtime, linked by cc
Executablea native program, no VM

Roadmap

Install and run

You need Rust stable and a C compiler (cc, gcc or clang). Works on Linux and macOS, x86-64 and ARM64.

Then read the getting started guide and the language reference.

git clone https://github.com/agnsha/om
cd om
cargo install --path crates/omc
om run examples/hello.om
om run   app.om            # compile and run
om build app.om -o app     # native executable
om check app.om            # type-check only

Help build a language

Om is open source under MIT or Apache 2.0. Small contributions matter: a clearer error message, a new example program, a test for an edge case.
