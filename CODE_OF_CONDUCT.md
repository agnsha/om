# Code of conduct

Om follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, give and accept constructive feedback
gracefully, and focus on what is best for the community. Harassment of any kind
is not tolerated.

Report unacceptable behaviour by opening a private security advisory on the
repository or contacting the maintainer through their GitHub profile.
