# The Om Book

A tutorial for Om, from your first program to ownership, traits and generics.
It assumes you've programmed before in some language, but not that you know
Rust. Each chapter is short and every complete program in it compiles and runs
with the current compiler.

1. [Getting going](01-getting-going.md): install, `om run`, `om build`, how a program is laid out
2. [A first project: grade report](02-grade-report.md): a whole small program before the details
3. [Common concepts](03-common-concepts.md): variables, types, functions, comments, control flow
4. [Ownership](04-ownership.md): how Om manages memory without a garbage collector
5. [Structs](05-structs.md): grouping data, methods
6. [Enums and pattern matching](06-enums.md): types with variants, `match`, `if let`
7. [Handling errors](07-errors.md): `Option`, `Result`, `?` and panics
8. [Collections](08-collections.md): `Vec`, `String`, `str` and `Box`
9. [Generics and traits](09-generics-traits.md): writing code once for many types
10. [Om's extras](10-extras.md): default and named arguments, `|>`, interpolation, `defer`
11. [What's next](11-whats-next.md): what Om can't do yet, and where it's going

Prefer to learn from code? [Om by Example](../by-example/README.md) covers the
same ground in short programs. Back to [Learn Om](../README.md).
